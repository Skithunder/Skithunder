Privacy Policy

This is a personal integration used only by its owner.

Google data accessed and used

With the owner's authorization, Hermes may access Google Calendar event details and Google Tasks lists and task details. It uses this data to answer the owner's requests and to make calendar or task changes when requested.

Storage and sharing

The Google OAuth token is stored in the Hermes profile on the machine running Hermes, not in this website or its public GitHub repository. Calendar or task details may appear in Hermes conversation history and may be sent to the AI model provider configured for Hermes to generate a response. The model provider's own data-handling terms apply.

This static website does not collect or store Calendar or Tasks data.

Revoking access

The owner can revoke the app's Google access in their Google Account security settings and remove the local Hermes token.
